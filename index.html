    Welcome to your workshop

    1. Type in Your code. Write the visible content between the opening <body> and closing </body> tags.
    2. Watch Your webpage. The preview changes as you type.
    3. Try a task. Choose a practice task on the left. “Load this starter” replaces your code after you confirm.
    4. Add some style. Select “Show CSS” to try colours, fonts and spacing.
    5. Keep your work. “Download page” saves an HTML file. Use “Open file” to carry on next lesson. Download again after making more changes.

    Images: “Add image” puts a copy inside your code, so it travels with the download. Change its alt text to describe it. Images must be PNG, JPEG, GIF or WebP and under 1 MB.

    On a shared computer: download first, then select “New page” to clear the saved project. Browser storage is not a school account or a backup.

    Preview scripts, forms, embedded pages and link navigation are disabled. Downloaded pages are ordinary HTML files; only open files you trust. This editor has no sign-in, tracking or class submission system.
